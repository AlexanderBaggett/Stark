# Samples

This directory contains Milestone 10 release-readiness sample projects.

Unlike the smaller `examples/` programs, these samples are organized as end-to-end project layouts with commands you can run directly from the repository root.

## `hello-world/`

Hosted executable that consumes the packaged `System` standard library.

## `multi-module/`

Small two-module application built directly from source files.

## `static-library-consumer/`

Two-step sample that builds a Stark static library package and then consumes it from a separate app directory through the manifest-backed package path.
