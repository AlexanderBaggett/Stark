# Examples

Canonical Stark examples live in the repository `examples/` directory and are
covered by integration tests.

The examples include:

- first programs and syntax tours
- borrowing examples with `borrow`, `mut borrow`, `retborrow`, moves, and `out`
- multi-module and static-library examples
- standard-library examples for console, files, directories, text, memory, and collections
- small systems projects such as a BitTorrent parser slice and a Git-like metadata tool
- native-backed Raylib bindings and Breakout examples

The examples directory also has `Stark.toml` project manifests and an
`examples/Stark.solution.toml` solution manifest for `stark build` and
`stark run`.
