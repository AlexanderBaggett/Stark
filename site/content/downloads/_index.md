# Downloads

Stark does not have published release artifacts yet.

For now, build from source:

```bash
dotnet build Stark.slnx
```

The repository also vendors the pinned Hugo binary used to build this site, and
the compiler can build examples directly from the source tree.

Future downloads should include:

- source archives
- platform-specific compiler builds
- standard-library package images
- checksums and release notes
